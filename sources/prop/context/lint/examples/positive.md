# Accepted design-lint refactor patterns

Curated reference for agents resolving `lint/errors/` cases. Each entry pairs a
finding with the refactor that resolved it and *why* that resolution is correct,
so future cases follow a proven shape instead of ad-hoc fixes.

**A subagent may append here ONLY after explicit maintainer approval** — never
infer approval from silence or "next". Read this file in full before resolving
any case.
