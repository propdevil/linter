# Rejected design-lint resolutions

Curated reference for agents resolving `lint/errors/` cases. Each entry records a
proposed resolution the maintainers **rejected** and the reason, so the same
wrong turn (suppression-for-convenience, fake abstractions, mass-annotation)
isn't repeated.

**A subagent may append here ONLY after the maintainer classifies a proposal as
negative** — never infer it. Read this file in full before resolving any case.
